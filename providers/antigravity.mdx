# Connect Antigravity CLI

This integration is for the `agy` command-line client. Install the official Antigravity CLI and complete its normal first-run sign-in before connecting. It is separate from any graphical Antigravity application.

```bash
agy
cmx setup --ask-connect-ready
cmx harness list
cmx harness enable antigravity
```

CMX places a reversible wrapper around `agy` so the CLI uses local CloudCode and Gemini routes. It keeps the original executable as a `.real` companion. Start a new `agy` process, send a request, then check `cmx stats`. The provider list may show Antigravity as ready based on the executable alone; a real request is the sign-in check.

## Return to the original CLI

```bash
cmx harness disable antigravity
```

This restores the original `agy` executable. `cmx stop` and `cmx uninstall` also restore wrapped clients before shutting down or removing CMX. If restoration fails, keep CMX installed and resolve the reported error before deleting any wrapper or `.real` file.
