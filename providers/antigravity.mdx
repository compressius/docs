# Connect Antigravity (IDE & CLI)

CMX provides native integrations for both the **Antigravity IDE** and the **Antigravity CLI (`agy`)**. Install Antigravity and sign in with your Google account before connecting.

```bash
cmx setup --ask-connect-ready
cmx harness list
cmx harness enable antigravity
```

CMX detects Antigravity installations and places reversible shims around their execution paths:
- **Antigravity IDE:** Wraps the internal `language_server` binary (located in your Antigravity installation's `resources/bin/` directory) so language intelligence and model requests route through local CMX CloudCode and Gemini proxies.
- **Antigravity CLI (`agy`):** Wraps `~/.local/bin/agy` (or platform equivalent) to export `CLOUD_CODE_URL` and `GOOGLE_GEMINI_BASE_URL` pointing to `127.0.0.1:17322`.

CMX preserves the original executables as `.real` companion binaries. Launch Antigravity IDE or start an `agy` session, send a query, and check `cmx stats` or `cmx harness verify` to confirm live traffic routing.

## Return to direct routing

```bash
cmx harness disable antigravity
```

This restores the original unmodified `language_server` and `agy` binaries. `cmx stop` and `cmx uninstall` also safely restore wrapped clients before shutting down or removing CMX. If restoration reports an edited config, resolve the conflict or use `cmx harness disable antigravity --force`.
