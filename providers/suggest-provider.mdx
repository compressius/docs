Do not see the coding agent or AI provider you use? Tell the CMX team which provider you want supported next, and we will look into building a first-class integration so compression works reliably out of the box.

## What to Include in Your Request

The more detail you can share, the faster we can evaluate the integration. Please include:

<CardGroup cols={2}>
  <Card title="Provider Name" icon="tag">
    The exact name of the coding agent, IDE extension, or AI app you want CMX to support.
  </Card>
  <Card title="How You Use It" icon="terminal">
    Your typical workflow, which model provider it talks to, and how you sign in.
  </Card>
  <Card title="Docs or Links" icon="link">
    Links to the tool's website, docs, or configuration guide for custom base URLs or proxies.
  </Card>
  <Card title="Why It Matters" icon="lightbulb">
    A short note on why compression would help, for example long sessions, expensive models, or heavy context reuse.
  </Card>
</CardGroup>

## Send Your Suggestion

Email us at [hello@compressi.us](mailto:hello@compressi.us?subject=CMX%20provider%20suggestion) with the details above. We read every message and use suggestions to prioritize the provider roadmap.

  hello@compressi.us
</Card>

<Note>
  In the meantime, most OpenAI- or Anthropic-compatible tools can already route through CMX today. See [Connect Any OpenAI or Anthropic Agent to CMX](/providers/custom-agents) for a manual setup using a custom base URL.
</Note>
