# Request an integration

CMX can configure [six coding clients](/providers/overview) and route to several [model providers](/model-providers). If yours is missing, send a request to [hello@compressi.us](mailto:hello@compressi.us?subject=CMX%20integration%20request).

Please include:

- The **coding client** or **model provider** name and version.
- Your operating system and whether you use a CLI or editor extension.
- A link to its public API or base-URL configuration documentation.
- The protocol it uses, if known: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, or another format.
- What you expected CMX to do.

Do not send API keys, raw prompts, responses, or private client configuration files. If the tool has a configurable API base URL, you may be able to use the [custom client guide](/providers/custom-agents) while a first-class integration is evaluated.
