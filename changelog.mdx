# Release notes and changes

The [GitHub releases page](https://github.com/compressius/cmx2/releases) is the source of truth for **published** versions, dates, downloadable assets, and checksums. Check `cmx --version` to see what is installed on your computer. A local release bundle or source change is not available to `cmx upgrade` until it is published.

## Changes covered by this documentation

This documentation update covers the current source behavior being prepared for release:

- Six supported coding clients: Codex, OpenCode, Claude Code, Aider, Antigravity CLI, and Cline CLI.
- Optional CMX account sign-in for local gateway use.
- Consent-aware installer setup. The Unix and Windows installers ask before connecting ready providers. `n` leaves clients direct and shows manual connection commands. An unavailable terminal produces an error instead of silently choosing an answer.
- Read-only `cmx providers <client> list`, so checking discovered providers cannot change OpenCode routing.
- Safer restoration: `cmx stop` restores client settings before stopping and retains the gateway if restoration fails. An explicit `n` during setup clears pending reconnection.
- Clearer separation of coding clients, upstream model providers, compression support, local storage, and cloud metrics.

These are documentation notes, **not** a claim that every published binary already contains every behavior. Check the installed version and its published release notes before relying on a change.
