# Update CMX

Check the installed version and look for a published update:

```bash
cmx --version
cmx upgrade
```

The check does not install anything. Read the [published release notes](https://github.com/compressius/cmx2/releases), then install when you are ready:

```bash
cmx upgrade --install
cmx --version
```

CMX verifies a downloaded release against its published checksum. A locally built version or source checkout is not automatically a published update. If `cmx upgrade` says you are current, there may be no newer public release even if development work exists.

If you installed the npm package, update it through the same package manager instead:

```bash
npm install --global @compressius/cmx@latest
# or
pnpm add --global @compressius/cmx@latest
```

Check `cmx status` after updating. Restart a long-running coding client when its routing settings change. Existing provider authentication remains in the native client; an update does not replace your provider account.

To stop using CMX, follow [Undo and uninstall](/uninstall) before deleting any executable or package.
