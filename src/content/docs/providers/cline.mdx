# Connect Cline

CMX detects Cline provider settings, including the CLI's `~/.cline/data/settings/providers.json` path and supported editor storage locations. Install Cline and sign in through Cline first. For the CLI, use `cline auth`; for the VS Code extension, use its own sign-in or provider settings.

```bash
cmx setup --ask-connect-ready
cmx providers cline list
cmx harness enable cline
```

CMX changes Cline's selected provider base URL and routing header. Reload your VS Code window or restart the Cline CLI, send a request, and check `cmx stats`. Provider availability and API behavior depend on the Cline mode you use; verify a real request before relying on the integration.

## Return to Cline directly

```bash
cmx harness disable cline
```

Reload the editor or restart Cline again. CMX restores the pre-connect client settings when the restore can be completed. If Cline changed the same routing field in the meantime, follow [Troubleshooting](/troubleshooting) before uninstalling CMX.
