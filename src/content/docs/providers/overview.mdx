# Supported AI coding clients

Compressius Maximus (CMX) is a free, local-first AI gateway that compresses conversation context for autonomous coding agents before requests reach your model provider. By pruning duplicate tool outputs and summarizing older chat history on `127.0.0.1:17322`, CMX reduces input token usage, cuts API billing, and prevents context rot.

A **coding client** is the interactive developer tool or CLI you work in (such as Codex, OpenCode, Claude Code, Aider, Google Antigravity, or Cline). A **model provider** is the upstream LLM service that powers it (such as OpenAI, Anthropic, Google Gemini, OpenRouter, or DeepSeek). CMX configures client routing so model traffic flows through the local compression gateway while leaving your native API credentials and models untouched.

## Why autonomous coding agents burn excessive tokens

Unlike single-turn chat interfaces, agentic coding tools operate in continuous multi-step reasoning loops. In each turn of an investigation or refactoring session, the agent:
1. Re-reads project files and directories.
2. Executes bash commands and test suites.
3. Receives long stack traces, compiler errors, or diffs.
4. **Re-submits the entire conversation history** back to the LLM on every subsequent tool call.

As a conversation stretches beyond 50 turns, submitting 80k–150k input tokens on *every single interaction* causes token consumption to compound quadratically. Developers frequently encounter surprise API bills and **attention degradation ("context rot")**, where the model begins forgetting earlier constraints or repeating failed edits.

## How CMX solves context bloat locally

CMX intercepts agent traffic on your local loopback address (`127.0.0.1:17322`):
- **Tool output pruning:** Automatically truncates obsolete terminal outputs and duplicate failed test logs while preserving active diffs.
- **Context compression:** Generates concise, validated summaries of older conversational turns once session length crosses your configured threshold.
- **Context protection:** Keeps the active system prompt, developer instructions, recent conversation tail, and protected tool calls 100% intact.
- **Privacy & security:** Your code and API keys never leave your machine; CMX Cloud receives only anonymous aggregate token counters when dashboard syncing is enabled.

## Discovered clients and harness commands

To inspect what clients and providers CMX detects on your machine:

```bash
# Check detected coding clients and routing status
cmx harness list

# Check discovered providers and credential readiness for a client
cmx providers codex list
cmx providers opencode list
```

Listing is read-only and makes zero configuration changes. To connect a detected client, follow the specific guide below or run `cmx setup --ask-connect-ready`.

## Restoring direct connections

You can disconnect any client and return to unproxied model routing at any time:

```bash
# Disconnect a specific client route
cmx providers codex disconnect api

# Or disable the client harness completely
cmx harness disable codex
```

For custom agent frameworks or tools with configurable API base URLs (such as LangChain, AutoGen, or bespoke agents), see [Custom clients](/providers/custom-agents). To learn about supported upstream LLM APIs, see [Model providers](/model-providers).
