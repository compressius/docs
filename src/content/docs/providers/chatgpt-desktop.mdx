# ChatGPT Desktop support

CMX does not currently have an automatic integration for the ChatGPT Desktop application. The app does not appear in `cmx harness list`, and there is no **CONFIG → ChatGPT Desktop** connection in CMX.

If you use OpenAI's **Codex** coding client, follow the [Codex guide](/providers/codex). Codex can use a ChatGPT sign-in through its `chatgpt` connection mode. That is a Codex integration; it does not change ChatGPT Desktop.

For another tool with a configurable API base URL, see [Custom clients](/providers/custom-agents).
