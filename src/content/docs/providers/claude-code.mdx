# Connect Claude Code for token optimization & cost reduction

Claude Code token optimization allows engineers using Anthropic's official Claude Code CLI to save on API tokens, mitigate context bloat, and lower costs on Claude 3.7 Sonnet, Claude 3.5 Sonnet, and Opus models. CMX runs locally on `127.0.0.1:17322`, intercepting requests via `ANTHROPIC_BASE_URL` to compress older context before sending tokens to Anthropic.

Claude Code is an autonomous CLI coding agent that navigates large codebases, runs tests, and applies code edits. In extended sessions, Claude Code frequently resubmits tens of thousands of historical tokens on every command, causing rapid token burn and higher API expenses.

## Why Claude Code burns substantial Anthropic tokens

Claude Code operates through continuous agentic loops:
- Reading source files, configs, and directory hierarchies.
- Executing terminal commands, linters, and unit tests.
- Storing every tool execution result directly in the active conversation context.

Because Anthropic bills per input and output token, re-transmitting 50k–150k input tokens on every turn of a complex task creates steep cost escalation. In addition to financial costs, accumulating massive context windows can cause **attention degradation**, where the model misses nuanced requirements mentioned early in the conversation.

## How CMX saves tokens in Claude Code

- **Pruning tool output noise:** Strips redundant terminal outputs, repeat compiler warnings, and obsolete test runs from older turns.
- **Context compression:** Replaces eligible older conversation history with compact, verified summaries once context reaches your threshold.
- **Preserving prompt caching synergy:** Retains the system instructions and recent context tail so Anthropic's prompt caching continues to function effectively.
- **Local privacy guarantee:** Your `ANTHROPIC_API_KEY` stays in your native environment. Code content is processed locally and forwarded directly to Anthropic's official endpoints.

## Setup: Connect Claude Code to CMX

Ensure Claude Code is installed and configured with your Anthropic API access (`ANTHROPIC_API_KEY`), then enable the CMX integration:

```bash
# 1. Inspect detected Claude Code status
cmx providers claude list

# 2. Connect Claude Code to the local gateway
cmx harness enable claude
```

CMX configures Claude Code's routing by setting `ANTHROPIC_BASE_URL` to point to the local CMX gateway on `127.0.0.1:17322`.

## Verify live token savings

1. Open a new terminal session or launch Claude Code.
2. Send a coding request or run a task in Claude Code.
3. Verify that requests route through CMX and observe real-time token savings:

```bash
# Confirm the connection to the running gateway
cmx harness verify

# Inspect live token compression metrics and savings estimates
cmx stats
```

## Return to direct Anthropic routing

To disconnect Claude Code and resume direct, unproxied connections to Anthropic:

```bash
# Disable the Claude Code harness
cmx harness disable claude
```

Restart Claude Code afterward. `cmx stop` also automatically restores direct routing before terminating the local gateway. If you need to keep Claude Code permanently direct, use `cmx harness disable claude`.
