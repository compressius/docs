# Frequently asked questions

## Do I need a CMX account?

No. You can use the local gateway without one. `cmx login` adds account-linked dashboard statistics. Your coding client still needs its own provider sign-in or API key.

## Which coding clients can CMX set up for me?

Codex, OpenCode, Claude Code, Aider, Antigravity CLI (`agy`), and Cline CLI. See [Supported clients](/providers/overview). ChatGPT Desktop is not a supported coding-client integration.

## Does CMX support my model provider?

CMX has [built-in upstream IDs](/model-providers) for common services and can route configured custom endpoints. A route alone does not supply credentials or guarantee that a provider's protocol is compressed. Check the native client's provider list and send a real request.

## Will installation change my client settings without asking?

The standalone Unix and Windows installers run `cmx setup --ask-connect-ready`. Answer `y` to connect ready providers, or `n`/Enter to leave them direct. If no interactive input is available, setup reports an error. You can later use `cmx providers <client> list` and `cmx providers <client> connect <id>` or the TUI **CONFIG** screen.

## What happens when I stop CMX?

`cmx stop` restores managed clients to direct settings before shutting down. If restoration fails, the gateway remains running and reports the conflict. A later `cmx start` may reconnect previously selected routes if their direct settings are unchanged. To stay direct, explicitly disconnect or disable the client. See [Undo and uninstall](/uninstall).

## Will CMX always reduce my provider bill?

No. Savings depend on session length, eligibility, model pricing, provider caching, and the extra summary call. `cmx stats` reports estimates, not an invoice. Short sessions may show no compression.

## Does summarization lose information?

It can. CMX protects instructions, recent context, protected tool exchanges, and opaque content, and validates each proposed summary. It cannot guarantee that a model-generated summary retains every detail. See [How compression works](/how-compression-works).

## Where do my prompts and code go?

Requests pass from your client through the local CMX gateway to your chosen model provider. CMX Cloud receives aggregate usage metrics only; it does not receive prompts, responses, or sessions. CMX stores local usage records and cached summaries. The optional lossless vault can also store original pruned content locally. See [Security and data handling](/security).

## Does CMX store my provider API key?

No. CMX does not persist or log provider API keys. The native client remains responsible for its own credential storage. Do not add keys to CMX's `config.json`.

## How do I remove everything?

Run `cmx uninstall` as the user who installed it. It restores managed clients before removing CMX. Then remove an npm/pnpm package registration or Windows PATH/shortcut entry if applicable. See [Undo and uninstall](/uninstall).
